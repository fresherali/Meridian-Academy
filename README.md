# 🎓 Academy Website – Smart Learning Solutions

A modern, responsive educational website designed to make quality education more accessible to Matriculation and Intermediate students through flexible learning options, including **On-Campus Classes, Home Tuition, and Online Learning**.

The platform provides students and parents with a centralized place to explore educational services, browse courses, understand fee structures, and connect with academic advisors for admission inquiries.

## 🌟 Project Overview

Finding reliable and suitable educational support can be challenging for students and parents. Traditional academies often provide limited learning options, while finding qualified home tutors or flexible online classes can require contacting multiple institutions and searching across different platforms.

This project aims to simplify that process by bringing different educational services together in one accessible platform.

The website provides a user-friendly digital presence for an educational academy, helping students explore their learning options and make informed decisions about their academic future.

## 🎯 Real-World Problem & Solution

### The Problem

Students and parents commonly face several challenges when searching for academic support:

- Limited flexibility in choosing between physical classrooms, home tuition, and online education.
- Difficulty finding suitable learning programs for Matric and Intermediate board examinations.
- Lack of centralized information about courses, educational services, and fee structures.
- Time-consuming admission and inquiry processes.
- Difficulty accessing educational information through a convenient digital platform.

### The Solution

This website addresses these challenges by providing:

- **Multiple Learning Options:** Information about on-campus classes, one-to-one home tuition, and online learning.
- **Centralized Course Information:** Organized subject and course details for grades 9–12.
- **Admission Inquiries:** A dedicated contact page with an inquiry form for students and parents.
- **Transparent Information:** Dedicated sections for academy details, educational services, and fee structures.
- **User-Friendly Experience:** Responsive layouts and intuitive navigation across desktop, tablet, and mobile devices.

## ✨ Key Features

- **Modern Homepage:** An engaging landing page introducing the academy and its educational services.
- **Educational Services:** Dedicated information about on-campus classes, home tuition, and online learning.
- **Comprehensive Courses:** Matriculation and Intermediate syllabus coverage for grades 9–12, including Science, Arts, and F.Sc streams.
- **About Us:** Academy background, mission, vision, and educational objectives.
- **Fee Structure:** A dedicated section for students and parents to explore educational fees.
- **Contact & Admission Inquiries:** An inquiry form to help prospective students connect with academic advisors.
- **Responsive Design:** Optimized layouts for different screen sizes.
- **Smooth Animations:** Interactive visual effects and page transitions for an improved browsing experience.
- **Easy Navigation:** Organized pages and navigation for convenient access to information.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/fresherali/Meridian-Academy.git
```

**2. Navigate to the project directory**

```bash
cd academy-website
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
